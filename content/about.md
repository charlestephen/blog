I'm Charles Stephen, and this is **The HandyHomo Homelab Blog** — a place to write
about the things I build and run: homelab infrastructure, self-hosting, networking,
automation, and whatever tech rabbit hole I'm down this week. Sometimes something
more personal sneaks in.

This site is three things at once:

- a **personal archive** — notes-to-future-me so I don't solve the same problem twice;
- a **professional showcase** — the work, in the open;
- a **place to think out loud** — half-formed ideas welcome.

No politics here. Just the fun stuff.

Comments run on [giscus](https://giscus.app) (GitHub Discussions) — a GitHub account
is all you need to join in.
